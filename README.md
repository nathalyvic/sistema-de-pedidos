# Sistema de Pedidos

API REST em Java + Spring Boot para cadastrar clientes, produtos e pedidos.

## Como rodar
1. Abrir o projeto na IntelliJ IDEA
2. Rodar a classe PedidosApplication
3. A API fica em http://localhost:8080

## Endpoints
- /api/clientes, /api/produtos e /api/pedidos
- GET (listar e buscar por id), POST, PUT e DELETE
- Id inexistente devolve 404 com mensagem
